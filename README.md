# Phone Addiction Level Predictor

Predicts a user's phone addiction level using demographic, psychological, and smartphone-usage behavioral data. We built a baseline Linear Regression pipeline (using pandas, scikit-learn, and matplotlib) and utilized Exploratory Data Analysis to identify and filter out artificially capped synthetic data.
